   。选择安装目录 d:\ti   （安装路径全部英文，无中文、无空格、无括号、无特殊符号）

   。双击 TexasInstruments.MSPM0G1X0X_G3X0X_DFP.1.3.1.pack ，直接进行安装
     实际本次安装在这个目录： C:\Users\HP\AppData\Local\Arm\Packs

1. 安装 sysconfig
   。双击 sysconfig~.exe
   。选择安装目录 d:\ti    （安装路径全部英文，无中文、无空格、无括号、无特殊符号）


2. 修改配置文件中的路径
   。进入目录： sdk目录\toos\keil
   。记事本打开 sycfg.bat, 修改路径x1

3. 在keil中加入sysconfig菜单
   。菜单tools\customize tools menu\import\选择上面的 ~import.cfg
   。可看到tools菜单列表下面，多出一栏sysconfig的菜单


4. 在keil工程中，通过刚才加入的菜单，打开sysconfig配置界面
   。打开示例empty
     . sdk目录\examples\nortos\LP_MSPMOG3507\deiverlib\empty\keil
     . 点击 .uvprojx，打开keil工程

   。尝试打开sysconfig配置界面
     . 点击左边栏的文件 empty.syscfg文件
     . 菜单 tools\点击sysconfig菜单
     . 弹出sysconfig界面，ok


5.  直接copy现有的empty工程 到sdk目录

========================== 绝对路径的empty示例 ============================


5.  直接copy现有的empty工程 到 D:\ti_base_test目录

6. 配置keil

    。魔法棒  -- user  --  before build\rebuild  --  修改为.syscfg.bat的绝对路径
       cmd.exe /C "D:\ti\mspm0_sdk_2_05_01_00\tools\keil\syscfg.bat '$P' empty.syscfg"

    。魔法棒  -- linker  --  misc controls --  把路径 修改为.a文件的绝对路径
       D:\ti\mspm0_sdk_2_05_01_00\source\ti\driverlib\lib\keil\m0p\mspm0g1x0x_g3x0x\driverlib.a

    。魔法棒  --  c/c++  --  在includ处  ，把相对路径修改成绝对路径如下：
       D:\ti\mspm0_sdk_2_05_01_00\source\third_party\CMSIS\Core\Include
       D:\ti\mspm0_sdk_2_05_01_00\source

7. 打开sysconfig配置界面
      。点击左边栏的文件 empty.syscfg文件
      。菜单 tools\点击sysconfig菜单
      。弹出sysconfig界面 
      。点击右边的“save”按钮，保存sysconfig相关的3个文件 
      。选择目录为；   D:\ti_base_test\empty
      。关闭 sysconfig界面 
      。跳出一个是否导入新的  sysconfig相关的3个文件 ，选择“yes，load all”
      。编译，应该compile ok  
 




========================== 新建自己的工程 ============================



5. 新建自己的工程myproject 之一

   。建目录  d:\ti\myproject
   。进入目录 sdk目录  --> 选中下面三个子目录
         .metadata
         source
         tools 

   。copy上面三个目录，到d:\tim\myproject中

5. 新建自己的工程myproject 之二

   。建目录d:\ti\myproject\keil
   。进入目录:  SDK目录\examples\nortos\LP_MSPM0G3507\driverlib\empty
   。把empty复制到目录： "SDK目录\" 里面 

   。选中 “SDK目录\ empty”里面下面4个文件，copy到d:\ti\myproject\keil中
     empty.c
     empty.syscfg
     ti_msp_dl_config.c
     ti_msp_dl_config.h

   。选中 SDK目录\ empty\keil\mspm0cfg3507.sct ，同样copy到d:\ti\myproject\keil中

5. 新建自己的工程myproject 之三
   。打开keil
   。菜单project\new project
   。选择目录:\ti\myproject\keil
   。输入工程名称prj1
   。跳出一个选择device的界面
   。device下拉框中选中 Software Packs
   。在下面列表中选中Texas Instruments的 MSPM0G3507
   。点击ok
   。跳出 software component界面，不要理他，点击cancel

5. 新建自己的工程myproject 之四                                     //或可以在左边栏重新直接导入文件
   。点击keil工具栏中的“品字按钮”（魔法棒右边）
   。跳出manage project items
   。在中间的groups输入下面2栏：
        . lib
        . user

   。选中上面lib，添加驱动文件，在右边的files里，点击下面的"add file"按钮   
   。進入目录 sdk目录\source\ti\driverlib\lib\keil\m0p\mspm0g1x0x_g3x0x
   。把下面的文件类型调到*.*， 选择driverlib.a文件，点击 “add”按钮

  。选中上面user，添加代码文件，在右边的files里，点击下面的"add file"按钮
   。進入目录D:\ti\myproject\source\ti\devices\msp\m0p\startup_system_files\keil\
   。把下面的文件类型调到*.*， 选择startup_mspm0g350x_uvision.s文件，点击 “add”按钮

   。再加入最开始复制的4个文件，点击 “add file”按钮，進入目录“d:\ti\myproject\keil”添加下面4个文件，点击 “add”按钮
     empty.c
     empty.syscfg
     ti_msp_dl_config.c
     ti_msp_dl_config.h

   。点ok，退出品字界面


5. 新建自己的工程myproject 之五
   。 点中左边栏的empty.syscfg文件 --   右键 option...   --  在file type处选择“text docment file"  -- ok
   。 点中左边栏的driverlib.a文件 --   右键 option...   --  在file type处选择“library file"  -- ok


5. 新建自己的工程myproject 之六
    。魔法棒  --  c/c++  --  在includ处，添加如下路径 
          .  D:\ti\myproject\source
          .  D:\ti\myproject\source\third_party\CMSIS\core\include


5.  新建自己的工程myproject 之七
    。魔法棒  --  c/c++  -- warning修改为 MISRA compatible
    。魔法棒  --  c/c++  -- optimization修改为 -o2
    。魔法棒  --  c/c++  -- define处加一个宏定义： _MSPM03507_

    。魔法棒  -- link  --  把”user memory layout...“前面的勾去掉
    。魔法棒  -- link  --  把scatter file里面的”.\mspm0g3507.sct“删掉，然后点"..."按钮，选择“ D:\ti\myproject\keil\mspm0cfg3507.sct"， 点ok
    。编译一下，应该是完全通过


5.  新建自己的工程myproject 之八
     . 点击左边栏的文件 empty.syscfg文件
     . 菜单 tools\点击sysconfig菜单
     . 弹出sysconfig界面，ok
 

 



补充： 绝对不要手写修改 ti_msp_dl_config.c，全部硬件参数在sysconfig的图形界面调
       一般直接拿 SDK 内 examples\nortos\MSPM0G3507 的 keil 工程模板来改，不要从零新建工程。
