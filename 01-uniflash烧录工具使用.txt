====================使用说明==============================



      1. 在下拉列表，不要点普通MSPM0G3507，往下找，选中：
         MSPM0G3507 (BOOTLOADER)

      2. 点 Edit，先配置串口参数
         Port：选择 CH340 对应的 COM 口号（去 Windows 设备管理器看端口）
         Baud rate：9600（固定，不能 115200）
         数据位 8，停止位 1，校验 None（8N1）
         保存退出 Edit。

      3. 准备让芯片进入 BSL 引导模式（关键时序）
         ①按住板子上 BSL 按键不放
         ②按一下复位 RST 按键
         ③松开 RST 按键
         ④延迟几十毫秒再松开 BSL 按键
         芯片进入 ROM 的 BSL 状态，只有10 秒左右的等待窗口，要抓紧下一步。

      4. 立刻点击 Start
          UniFlash 打开串口，尝试和芯片 BSL 握手。

      5. Start 成功之后界面
         进入烧录会话，点 Browse，选中你的.hex固件文件
         Operation 选择：Erase and Program（擦除 + 烧录）
         点击 Load Image，开始烧录


      6. 高频踩坑
         接线必须交叉：
         CH340?TX → BSLRX(PA11)；CH340?RX → BSLTX(PA10)，接直接完全无法握手。
         BSL 时序错，直接报 timeout；不要先松 BSL 按键。
         波特率错直接失败，必须 9600。
         BSL 不稳定，握手失败就重复复位 + BSL 按键整套流程。
         建议：如果手上有 J?Link/DAPLink，优先 SWD 调试下载；BSL 只做救砖手段。



====================参考=============================


uniflash_sl.8.7.0.4818.exe
UniFlash‑SL = UniFlash Standalone（独立单机版烧录工具）
版本：8.7.0，build 号 4818，TI 官方独立 Flash 烧写软件，不用安装 CCS 也可以单独跑，专门给 TI 芯片烧固件（MSPM0/MSP430/C2000 等）。
通俗解释
SL → Standalone 独立版
普通 UniFlash 分两种：
①集成在 CCS 内部（装 CCS 就自带）；
②uniflash_sl.exe独立安装包，电脑不装 CCS，单独拿来烧芯片，量产经常用这个。
能干什么（MSPM0G1507）
烧写 .elf / .hex / .bin 固件；
支持 XDS110、J‑Link、DAPLink 仿真器 SWD 下载；
也支持串口 BSL 烧录（不用仿真器，串口 TTL）；
整片擦除、读回 Flash、设置调试锁密码；
带 GUI 图形界面，同时支持命令行 dslite 脚本做批量量产烧录德州仪器。
和 CCS 里面烧录的区别

表格

uniflash_sl 独立版	CCS 内部烧录
是否要装 CCS	❌不需要，单独安装	✅必须装完整 CCS
用途	只做烧录，不写代码、不调试单步	写代码、调试、烧录一体

使用场景	量产、只烧固件，不用开发 IDE	日常开发写代码调试
注意坑点
电脑 Windows 用户名不能中文，否则烧写会卡住报错。
安装路径不能中文、空格，建议放 D:\ti\uniflash_8_7_0。
版本 8.7.0 可以完美支持 MSPM0G1507。
它不能做代码调试（断点、看变量），仅烧写 Flash。
举例子：
你写代码用 CCS；给产线工人电脑，就只装这个uniflash_sl，工人不用装庞大 CCS，直接烧固件。
简单总结
uniflash_sl = 脱离 CCS 的独立 TI 烧录器软件，只管下载固件，不能写代码调试。
